Glasshead

A small transformer, the same kind of neural network behind today’s AI chatbots, with its own autograd engine, written from scratch in TypeScript. It trains live in your browser on algorithmic tasks, and every attention head is drawn as it learns, so you can see the algorithm the network discovers.

Parameters

Engine: reverse-mode autodiff on Float64 tensors · pre-LayerNorm transformer block · GELU · AdamW with warmup + cosine decay · gradient clipping · seeded RNG. Training runs in a Web Worker so the page stays responsive.
